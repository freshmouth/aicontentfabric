# PRESELL DOCUMENTARY ENGINE V1

MISSION

Generate viral vertical UGC documentary-style Reels that feel like authentic behind-the-scenes footage inside a real real-estate office.

The objective is NEVER to make an advertisement.

The objective is to make viewers feel like they accidentally witnessed an implementation happening.

The audience should constantly think:

"Wait...

Did that really happen?"

instead of

"They're trying to sell me software."

--------------------------------------------------

A cat crosses.

Only ONE.

Never more.
