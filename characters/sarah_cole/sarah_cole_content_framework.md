## 4. VISUAL OBJECT LIBRARY

Objects are selected for three criteria:  
(1) Creates visual dissonance against the professional office set  
(2) Photographically interesting at close range  
(3) Reframes a problem — never suggests a specific food or remedy

### Category A — Everyday villain (reframed as threat)
```

Skim milk carton

Low-fat yogurt container
Coffee creamer tub
Generic protein powder tub
Blister pack of generic white pills (no brand, no readable label)
Commercial probiotic bottle
Ibuprofen bottle (generic, label not readable)
```

### Category B — Binary contrast pairs
```
White refined salt vs grey unrefined salt (on two wooden spoons)
White sugar packet vs dark coconut sugar
Blister pack pills vs whole food item (category only, not specific)
Regular coffee vs morning tonic glass
Commercial supplement bottle vs glass of water
```

### Category C — Body reference gestures
```
Hand placed on abdomen — pointing at belly
Pointing at under-eye area
Pressing two fingers to temple (brain fog)
Holding throat area (thyroid signal)
Showing inner wrist (pulse / circulation)
Touching jawline (skin signal)
```

### Category D — Neutral authority props
```
Open book face-down on desk
Closed book with hand resting on cover
Printed chart or graph (not readable)
Glass of plain water
Ceramic mug (no visible branding)
```

> **Critical rule:** Objects only CALL OUT the problem. No object suggests  
> a specific food, ingredient, or natural remedy as the solution.  
> The solution is only delivered via DM after comment trigger.

## 5. HOOK CAPTION FORMULA

The caption overlay appears on the first frame — visible before audio,  
before the viewer decides to tap. Works simultaneously with the visual hook.

### Structure
```
LINE 1 (largest, bold, white + black drop shadow):
  The disruption — 5 words max — challenges a belief or names a threat

LINE 2 (smaller, italic, warm white or sage):
  The qualifier — "if you're over 40" / "in perimenopause" / "after menopause"

LINE 3 (optional, bold):
  Consequence or unresolved promise — creates urgency, no answer given
```

### Typography rules
```
Font:       Bold sans-serif (e.g. Montserrat Bold or similar system font)
Line 1:     Large — approx 7–8% of frame height
Line 2:     60% of Line 1 size, italic
Line 3:     Same size as Line 2, bold
Color:      White with 2px black drop shadow — readable on any background
Position:   Lines 1–2 in upper third of frame
            Line 3 in lower third if used
Never:      Full sentences / punctuation at end of Line 1 / more than 3 lines
```

## 6. SCRIPT FRAMEWORK (5-BLOCK STRUCTURE)

Every script follows this structure exactly. No exceptions.  
The solution is NEVER named in the video. Only the problem is resolved by reframe.

### Block 1 — HOOK [0:00–0:05]
```
Purpose:    Create the question the viewer must stay to answer
Rule:       Never explain — only create tension
Max length: 2 sentences
Formula:    [Disruption statement] + [pause signal] + [promise of reframe]

Delivery:   Slightly urgent — eyebrow-raise energy
            First sentence ends with a hard stop
            0.8s pause before second sentence minimum
```

### Block 2 — PROBLEM [0:05–0:22]
```
Purpose:    Name the mechanism — why this happens specifically after 40
Rule:       Validate her experience — she's not crazy, there's a biological reason
            Never blame the audience — always blame the system or the biology
Formula:    [Common belief she holds] + [what actually changes after 40]
            + [specific biological mechanism, named clinically]
            + [consequence she recognizes from her own life]

Delivery:   Matter-of-fact, slightly heavy — delivering important news
            Pause 0.6s minimum after every mechanism statement
            Longest pause (1.2–1.4s) after the strongest consequence line
```

### Block 3 — REFRAME [0:22–0:40]
```
Purpose:    Shift the frame from "I'm broken" to "I've been missing information"
Rule:       DO NOT name a specific food, supplement, or natural remedy
            DO NOT say "eat this" / "take this" / "use this"
            DO name the category of support the body needs
            DO reference that "what to actually do" is in the protocol
Formula:    [What the body is actually asking for, category level]
            + [why conventional approaches miss this]
            + [what the right approach addresses]
            + [reference: "I put the full protocol in the guide I send"]

Example reframe language:
  "Your body isn't asking for less food — it's asking for 
   the right mineral support at the right time."
  
  "This isn't a willpower problem. It's a hormone timing 
   problem. And the solution isn't a diet — it's a protocol."
  
  "What actually works here isn't what the wellness industry 
   sells you. It's more specific than that. I send the exact 
   breakdown to anyone who comments [KEYWORD]."

Delivery:   Warm shift — kitchen-table friend energy
            More conversational than Block 2
            Pace slows slightly — let the reframe land
```

### Block 4 — PROOF [0:40–0:52]
```
Purpose:    Sarah's personal result as evidence of the reframe
Rule:       Specific timeline + specific change — not "I felt amazing"
            Same woman, different information — not willpower or discipline
Formula:    [Specific timeline] + [first measurable change]
            + [second measurable change]
            + [reframe closing: "same body, different inputs"]

Example:
  "Three weeks after I understood what was actually happening —
   not three months, three weeks — my sleep changed first.
   Then the 3am waking stopped. Then the weight started moving.
   Same woman. Same body. Finally the right information."

Delivery:   Quieter, more personal — slight smile in the voice
            Each timeline marker gets its own breath
            Final "same woman / same body" fragments with pauses between
```

### Block 5 — CTA [0:52–1:00]
```
Purpose:    Single keyword trigger → ManyChat DM → product link
Rule:       One keyword only. One promise only. Two sentences maximum.
            Never mention the product in the video.
            Never say "I'll send you a supplement" or "buy this."
            Promise: the protocol / the guide / the breakdown

Formula:
  "Comment [KEYWORD] below and I'll send you the exact protocol —
   [specific promise tied to this video's front]."

CTA keyword map:
  F1 Sleep     → SLEEP   — "the exact sleep protocol I followed"
  F2 Weight    → GLUCOSE — "the morning glucose protocol"
  F3 Gut       → CLEANSE — "the 72-hour gut reset protocol"
  F4 Energy    → FOCUS   — "the adrenal reset protocol"
  F5 Mood      → CALM    — "the cortisol protocol for mood"
  F6 Skin      → GLOW    — "the skin protocol from the inside"

Delivery:   Direct and calm — not pushy, not urgent
            Looking straight into lens
            Slight downward pitch on final word — signals confidence
```

## 9. CAPTION ASSEMBLY (POST-PRODUCTION)

Text overlays are added after video generation — not by Gemini.

### Layer 1 — First frame caption (scroll-stop)
```
Position:   Upper third of frame
Timing:     0:00 → 0:04 (visible before audio decision)
Style:      Bold sans-serif, white, 2px black drop shadow
Line 1:     [DISRUPTION — 5 words max, largest text]
Line 2:     [QUALIFIER — italic, 60% of Line 1 size]
Line 3:     [CONSEQUENCE/PROMISE — optional, bold]
```

### Layer 2 — Mechanism terms (mid-video)
```
Timing:     Appears 0.5s after the term is spoken
Duration:   1.5s on screen
Style:      Bold, white or sage green
Examples:   "CORTISOL SPIKE" / "INSULIN RESISTANCE" / 
            "ESTROGEN REABSORPTION" / "PROGESTERONE DROP"
Rule:       Maximum 3 mid-video text overlays per video
            Never overlay during CTA block
```

```
Position:   Center frame, lower third
Timing:     0:50 → end
Style:      Large, bold, animated pulse or fade-in
Text:       "Comment [KEYWORD]" + arrow emoji pointing down
Rule:       Must appear while Sarah is speaking the CTA line
            Remove all other overlays during this layer
```

## 11. DAILY AGENT EXECUTION CHECKLIST

The agent runs this sequence every day using the weekly rotation calendar.

```
STEP 1 — READ CALENDAR
  Input:  Current day of week
  Output: Front (F[x]) + Hook type (H[x]) + CTA keyword

STEP 2 — SELECT OBJECT
  Input:  Front selected
  Output: Specific object from Object Library (Category A/B/C/D)
  Rule:   Do not repeat same object used in previous 7 days

STEP 3 — ASSEMBLE CAPTION
  Input:  Front + Hook + Object
  Output: 3-line caption (Line 1 / Line 2 / Line 3)
  Rule:   Line 1 max 5 words. No full sentences.

STEP 4 — GENERATE STARTING IMAGE
  Tool:   GPT Image 2
  Input:  Master Block + Object Variable Block + Hook Action
  Output: 9:16 vertical image, saved as [DATE]_[FRONT]_[HOOK]_frame.png

STEP 5 — GENERATE VIDEO
  Tool:   Google Gemini Flash Video (Veo)
  Input:  5-block prompt + starting image from Step 4
  Output: 60s video saved as [DATE]_[FRONT]_[HOOK]_video.mp4

STEP 6 — WRITE SCRIPT
  Input:  Front + Hook + Object + Audience State + CTA keyword
  Output: 5-block script with [pause] markers
  Rule:   Block 3 (Reframe) must never name a specific food or supplement
          Block 5 (CTA) uses only the keyword — no product mention

STEP 7 — ADD CAPTION OVERLAY
  Tool:   Post-production text layer (any tool)
  Input:  Caption from Step 3 + video from Step 5
  Layer 1: First frame caption (0:00–0:04)
  Layer 2: Mechanism terms (timed to script)
  Layer 3: CTA keyword end card

STEP 8 — QUALITY CHECK
  □ Character face matches master reference
  □ Set elements present (certificate, books, olive tree)
  □ No specific food or supplement mentioned in video
  □ No product link or mention in video content
  □ Caption Line 1 is 5 words or fewer
  □ CTA keyword matches front being addressed
  □ Video duration: 55–65 seconds

STEP 9 — PUBLISH
  Platform:   Instagram Reels (primary) + TikTok (simultaneous)
  Time:       [Set per account analytics — typically 7–9am or 6–8pm local]
  Caption:    Written caption with hashtags (separate from overlay)
  ManyChat:   Confirm keyword trigger is active before publishing

STEP 10 — LOG
  Record: Date / Front / Hook / Object / Caption Line 1 / CTA keyword
  Track:  Comment volume per keyword (weekly review)
  Review: Every 7 days — identify top-converting Front + Hook combination
          Double production on winning combination the following week
```
